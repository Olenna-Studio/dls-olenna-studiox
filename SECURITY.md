# Security Policy

## Supported Versions

Only the current stable release receives active security patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within the Olenna StudioX design system or associated packages, please **do not open a public issue**.

Instead, email our security team directly:
**security@olenna.com**

Please include:
- Package name and affected version.
- Step-by-step reproduction instructions or proof-of-concept.
- Potential impact on consuming web applications.

We will acknowledge receipt within 48 hours and provide an estimated remediation timeline.
