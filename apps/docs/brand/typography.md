# Typography

Olenna's typographic pairing harmonizes an editorial Roman serif with an ultra-legible modern sans-serif.

## Typeface Hierarchy

### Editorial Serif — Playfair Display
- **Role**: Headings (H1 to H3), luxury titles, magazine quotes, and logo wordmark.
- **Font Stack**: `'Playfair Display', Georgia, Cambria, 'Times New Roman', serif`
- **Weights**: 500 (Medium), 600 (SemiBold), 700 (Bold).

### Workhorse Sans-Serif — Plus Jakarta Sans
- **Role**: Body copy, form labels, data grids, buttons, and mobile navigation.
- **Font Stack**: `'Plus Jakarta Sans', system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
- **Weights**: 400 (Regular), 500 (Medium), 600 (SemiBold).

### Monospace — JetBrains Mono
- **Role**: Order tracking numbers, SKU codes, tabular financial figures, and code samples.
- **Font Stack**: `'JetBrains Mono', SFMono-Regular, Menlo, Monaco, Consolas, monospace`
